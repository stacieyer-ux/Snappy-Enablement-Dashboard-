How scores are calculated

Learning (Juno Journey)

  • Financial Literacy — Not started = 0, In progress = 50%, Complete = 100%
  • Moments to Momentum (M2M) — Not started = 0, In progress = 50%, Complete = 100%
  • Score = average of both courses

Prospecting (Sales Reps only)

  • Sales Navigator — average of 4 inputs:
  • Days active — target 12/mo
  • Searches performed — target 60/mo
  • Profile views — target 100/mo
  • InMails sent — target 12/mo
  • ZoomInfo — average of 3 inputs:
  • Logins — target 20/mo
  • Credits used — target 100/mo (based on team avg)
  • Searches — target 100/mo
  • Score = avg(Sales Nav score, ZoomInfo score)

Call Review (Gong)

  • Calls listened — target 12/mo (3 per week)
  • Activity window: last 30 days
  • Score = calls listened / 12, capped at 100%

Role weights

  • Sales Rep — 30% Learning, 35% Prospecting, 35% Call Review
  • CSM — 60% Learning, 40% Call Review
  • Manager — 60% Team avg, 25% Call Review, 15% Learning
  • Amelia Cotton — 100% Call Review
  • Christina Lian Nunez — 50% Learning, 50% Call Review
  • Staci Eyer — 60% Amelia's Call Review, 40% own Call Review
All inputs capped at their target (max contribution = 100%). Data window = last 30 days. Prospecting applies to Sales Reps only. Manager scores roll up recursively from direct reports. ZoomInfo credit benchmark based on 30-day team average. Sales Navigator searches benchmark based on industry best practices.
